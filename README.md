# FitCore — Fitness & Gym Management Website

A bold, modern and responsive fitness club website concept built with HTML, CSS and vanilla JavaScript. FitCore showcases gym programs, coaching profiles, membership plans and contact options in a high-energy visual style.

## Live Demo

After enabling GitHub Pages, the website will be available at:

`https://mkaceduet-hub.github.io/fitness-gym-management-website/`

## Features

- Responsive desktop, tablet and mobile layouts
- Fitness-focused hero section and club highlights
- Strength, personal training and group fitness program cards
- About section and coaching team profiles
- Three sample membership plan cards
- Contact form with browser-side validation and confirmation
- Mobile navigation menu
- Semantic page sections and accessible form labels

## Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No package installation or build process is required.

## Enable GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`.
5. Click **Save** and wait for the deployment to finish.

## Demo Notes

This is a front-end portfolio project, not a production gym management system. The contact form displays an on-page demo confirmation and does not send or store submissions. Membership prices, trainer names, club details and contact information are illustrative placeholders. Replace them with verified business information before using the site commercially. Membership payments, member accounts, class booking and gym management require a secure backend and suitable integrations.
